# Steward · 个人生活管家

> 我的个人生活管家。与 [Deputy](https://github.com/zjjiang/deputy)（事业助手）相对应，
> Steward 负责我的**个人生活**。

第一阶段只聚焦两个方向：

- **Finance** — 理解我的消费与财务状态（复用 [credi-insights] 已有数据），能回答问题、主动发现值得关注的趋势。
- **Fitness** — 用自然语言记录运动（"今天跑了 8 公里"），管理简单目标，发现运动状态变化。

核心理念：**输入足够轻、不只是记录而是理解、Review（周/月复盘）是核心场景。**

详见 [docs/PRD-第一阶段.md](docs/PRD-第一阶段.md)。
